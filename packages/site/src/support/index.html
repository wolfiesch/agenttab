Get help with AgentTab.

AgentTab v2.0.0-rc.1 is unreleased. This page is the support destination for the release candidate and does not announce public availability.

Report a problem

Use the public AgentTab issue tracker for installation failures, defects, compatibility problems, and documentation corrections.

Open an AgentTab issue

Include useful details

Include the AgentTab version, operating system, Chrome version, the command or action that failed, and the smallest reproducible sequence. Include logs only after reviewing and redacting them.

Keep private data private

Do not post passwords, passkeys, access tokens, cookies, browsing data, private page content, local file paths, or unredacted audit records in a public issue.

Read the AgentTab privacy policy for the product's local-data boundaries.
