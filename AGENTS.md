# Agent notes

- In Codex Desktop, use the Computer Use plugin for Chrome-owned UI such as `chrome://extensions`, reloading the unpacked extension, and checking extension state. Re-query Chrome after every UI action because accessibility element IDs become stale. Use terminal commands for AgentTab health checks and background behavior tests after the UI step.
- Background reliability tests must compare active Chrome window/tab IDs, not active-tab URLs. The user may navigate inside the same active tab during a soak; that is normal human activity and is not focus stealing.
- Task-session cleanup must delete and persist the session record before calling `chrome.tabs.remove`. Tab removal emits `tabs.onRemoved`; removing tabs first lets that event race and re-save an empty session record.
- Chrome's debugger notice is browser-wide, so a tab group cannot contain it. Compact and full accessibility snapshots both need Chrome's real debugger-backed accessibility tree. Keep text/HTML reads and text waits on `chrome.scripting`; for debugger-backed actions on task-owned or manually grouped tabs, reuse the task connection and let its idle timer detach instead of attaching and detaching around every command.
- Generate the extension PNG icons from `packages/extension/src/icons/icon-source.svg` with `rsvg-convert`. On this Mac, ImageMagick accepted the SVG without an error but silently omitted the violet and teal path strokes, producing a spark-only icon.
- On this Mac, Homebrew Python 3.14 may fail to import `pyexpat` with a missing `XML_SetAllocTrackerActivationThreshold` symbol. This breaks `plistlib`, `xml.etree`, `verify_benchmark_harness.py`, and `setup-broker.sh` even though the AgentTab runtime code is healthy. Confirm with `python3 -c 'import pyexpat'`. Until Homebrew Python is repaired, run XML-only checks with `/usr/bin/python3` and invoke broker setup with `/usr/bin` before `/opt/homebrew/bin` in `PATH` so system Python writes the plist while Homebrew Node remains available.
